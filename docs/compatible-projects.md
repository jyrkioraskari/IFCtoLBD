# Compatible projects

These projects complement IFCtoLBD by working with Linked Building Data or by
providing another way to use the same workflows and outputs:

- [IDStoSHACL](https://github.com/jyrkioraskari/IDStoSHACL) converts
  Information Delivery Specification (IDS) requirements into SHACL shapes for
  RDF validation.
- [IFCtoLBD Python](https://github.com/jyrkioraskari/IFCtoLBD_Python) is a
  native Python implementation of the IFC-to-LBD conversion workflow, built
  with IfcOpenShell and RDFLib.
- [LBD OBJ Exporter](https://github.com/jyrkioraskari/LBD_OBJ_Exporter)
  exports Wavefront OBJ geometry from Linked Building Data.
- [LBD Viewer](https://github.com/jyrkioraskari/LBD-Viewer) provides a viewer
  for exploring Linked Building Data and its geometry.

Each project is maintained separately. See its repository for installation,
usage, supported formats, and current compatibility details.
